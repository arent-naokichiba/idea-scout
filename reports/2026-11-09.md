## 注目の開発ネタ候補

### ★★★★ [KetchUp – Open-source SketchUp alternative built with Rust and WebGPU](https://ketchup3d.github.io/app/)
- ソース: Hacker News / カテゴリ: BIM/CAD
- 要約: RustとWebGPUで構築されたオープンソースのSketchUp代替3Dモデリングツール。ブラウザ上で動作。
- 開発ネタ: BIM/CADツールのWebベース実装の参考に。WebGPUベースの3Dビューアを自作してRevitモデルをブラウザで表示する、IFCビューアをWASM+WebGPUで実装する、といった応用が考えられる。Rustの安全性とWebGPUのパフォーマンスを活かした建築3Dツール開発の参考事例として注目。

### ★★★★ [Cognitive Tours: Making Understanding a Deliverable in AI-Assisted Development](http://arxiv.org/abs/2611.08456v1)
- ソース: arXiv / カテゴリ: AI
- 要約: AIコーディング支援が加速する中、「認知負債」「意図負債」という新たな技術的リスクが浮上。AIが生成したコードの理解不足がチームの知識蓄積を阻害するという問題提起。
- 開発ネタ: RevitアドインやIFCツール開発においてAIコード生成を活用する場合の「認知負債」対策ツールのアイデア。コード生成後に自動でコードツアー（Cognitive Tours）を生成するClaude Code拡張、AIが生成したRevit APIコードの意図を記録・説明するドキュメント自動化ツールなどが考えられる。

### ★★★★ [Accepted but Wrong: Silent Failures of LLM Code Repairs after API Migrations](http://arxiv.org/abs/2611.08269v1)
- ソース: arXiv / カテゴリ: AI
- 要約: API移行後にLLMが修正したコードがランタイムエラーなく動くが誤った結果を返すというサイレント障害を73タスクで実証研究。CPython, Node.js, SQLiteでの事例を報告。
- 開発ネタ: Revit APIのバージョンアップ（例: Revit 2024→2025）時にAIでコードを自動修正するツールの落とし穴として直接関連。AIによるRevitアドインのAPI移行支援ツール開発時に、テストカバレッジと期待値検証の重要性を示す。LLMコード修正の検証フレームワーク、差分テスト自動生成ツールの開発ネタになる。

### ★★★ [Llama-modchip: 284B DeepSeek on 64GB RAM, no GPU](https://github.com/synchopate/llama-modchip)
- ソース: Hacker News / カテゴリ: AI
- 要約: GPU不要でCPUのみで284Bパラメータの大規模LLMをローカル実行可能にする手法。64GB RAMで動作。
- 開発ネタ: オフライン環境や社内ネットワーク制限のある建設現場・設計事務所でのAI活用に道を開く。RevitアドインにローカルLLMを組み込み、インターネット接続不要でAI設計支援を行うツール開発の参考に。

### ★★★ [Hard Issue, Weak Model, or Bad Run? Rethinking Failure Prediction for Coding Agents](http://arxiv.org/abs/2611.08285v1)
- ソース: arXiv / カテゴリ: AI
- 要約: AIコーディングエージェントの失敗を「問題の難しさ」「モデルの弱さ」「実行の揺らぎ」の3軸で分析。失敗予測器の汎化性能を再検討。
- 開発ネタ: Revitアドイン自動生成やIFCデータ変換をAIエージェントで行う際の信頼性評価フレームワーク設計に活用できる。どんな課題がAIに適しているかを判断する指標づくりのヒントになる。

### ★★★ [ControlAnything: Generative UI and On-Demand Device Integration for Mixed-Reality Hand Interaction by a Coding Agent](http://arxiv.org/abs/2611.08321v1)
- ソース: arXiv / カテゴリ: AI
- 要約: Meta Quest 3上でコーディングエージェントがMR手入力と物理デバイスを動的に連携するUI生成システム。その場でコードを生成・実行してデバイスを制御。
- 開発ネタ: BIMモデルのMRレビュー時にAIエージェントがRevit操作やIFCエクスポートをその場で実行する未来的なワークフローへの応用。建築MRビューア + AIエージェント連携ツールの開発参考に。
