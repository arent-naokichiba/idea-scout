### ★★★★ [DSL-Bench: Evaluating and Explaining LLM Code Generation Across Domain-Specific Languages](http://arxiv.org/abs/2611.05168v1)
- ソース: arXiv / カテゴリ: AI/DevTools
- 要約: LLMのコード生成をDSL（ドメイン固有言語）で評価するベンチマーク。DSLはGPL（汎用言語）とは異なる構文・検証要件を持ち、LLMの対応能力を体系的に測定する。
- **開発ネタ**: Dynamo（Revit用ビジュアルスクリプティングDSL）やIFCスキーマをDSLとして扱い、LLMにRevitアドインのコード生成を指示するシステムの評価フレームワーク構築。「Revit API × LLM」の信頼性測定にそのまま応用できる。

- **開発ネタ**: Revitアドイン開発にSDD+AIエージェントを導入する実践的アプローチ。IFCエクスポーター仕様書 → Claude Codeが実装 → 人間がゲート承認、という自動化パイプラインの構築に直接活用できる。
