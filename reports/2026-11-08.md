### ★★★★★ [ControlAnything: Generative UI and On-Demand Device Integration for Mixed-Reality Hand Interaction](http://arxiv.org/abs/2611.08321v1)
- ソース: arXiv / AI
- 要約: Mixed Reality環境でコーディングエージェントがその場でデバイス統合UIを生成し、手入力で物理デバイスを操作できるシステム。Meta Quest 3で実証。

### ★★★★ [Cognitive Tours: Making Understanding a Deliverable in AI-Assisted Development](http://arxiv.org/abs/2611.08456v1)
- ソース: arXiv / DevTools
- 要約: AIコーディングツールが生成するコードで「認知的負債」が蓄積するリスクを指摘し、チームの共有理解を成果物として扱う「Cognitive Tours」手法を提案。
- 開発ネタ: Revitアドイン開発にAIコーディングを導入する際のドキュメント自動生成ツールに応用できる。IFCスキーマの複雑さをAIが要約・可視化する「BIM理解補助ツール」の研究ベースになる。

### ★★★★ [Hard Issue, Weak Model, or Bad Run? Rethinking Failure Prediction for Coding Agents](http://arxiv.org/abs/2611.08285v1)
- ソース: arXiv / AI
- 要約: コーディングエージェントの失敗要因（問題の難しさ/モデル能力/実行の揺らぎ）を分離して予測するフレームワーク。失敗を事前検知してモデル切替・リトライを行う。
- 開発ネタ: Revitアドイン自動生成AIツールで、タスク難易度を事前評価し適切なモデルを選択する仕組みに応用可能。BIM処理の複雑なジオメトリ操作タスクの失敗予測モジュールとして活用できる。

### ★★★ [Accepted but Wrong: Silent Failures of LLM Code Repairs after API Migrations](http://arxiv.org/abs/2611.08269v1)
- ソース: arXiv / AI
- 要約: LLMによるAPIマイグレーション後のコード修正が、実行は通るが結果が誤るケースを73タスクで実証。CPython/Node.js/SQLiteで検証。
- 開発ネタ: Revit APIのバージョンアップ時のアドインコード自動移行ツールを開発する上で、サイレント失敗の検出テスト戦略として直接応用できる。RevitのAPIマイグレーション（2024→2025等）の自動化検証ツールの研究ベースに。

### ★★★ [Claude Code's "Don't Ask Again" exposes passwords in 1,122 public GitHub files](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again)
- ソース: Hacker News / Security
